# Guía de GitHub · Hackatón IIA

Todo se hace **desde la web**, sin terminal. Necesitan la cuenta que crearon en la Clase 12 y el celular a mano por si GitHub pide verificación.

## 1. Fork (lo hace UN integrante)

1. Inicien sesión en github.com.
2. Entren al repositorio de la cátedra: **github.com/dharioprodigio/hackaton-iia-uade-2026**
3. Arriba a la derecha, botón **Fork** → **Create fork**.
4. Ahora tienen una copia en su cuenta: `github.com/<su-usuario>/hackaton-iia-uade-2026`. Ese es **su repositorio**, para siempre.

> Fork = partir del estado de otro (Clase 12). Desde acá, lo que cambien queda en su copia, no en la de la cátedra.

## 2. Sumar al compañero

1. En **su** fork: **Settings** → **Collaborators** → **Add people**.
2. Escriban el usuario del compañero.
3. El compañero acepta la invitación desde el mail o desde github.com/notifications.

## 3. Primer commit: completar el encabezado del README

1. En su fork, abran `README.md` y toquen el lápiz ✏️ (**Edit this file**).
2. Reemplacen `<Código>`, `<Título…>`, integrantes, IA declarada y pista.
3. Botón **Commit changes…** → escriban un mensaje claro, por ejemplo `Encabezado y pista` → **Commit changes**.

> Commit = una foto del proyecto en un momento (Clase 12). El historial de commits es el camino que siguieron.

## 4. Subir archivos (Colab, planilla, imágenes)

- Colab: **Archivo → Descargar → Descargar .ipynb**.
- En su fork: **Add file → Upload files** → arrastren el archivo → **Commit changes**.
- Para que se pueda correr en vivo, pongan en el README el link al Colab con acceso de lectura.

## 5. Durante el hackatón

- Hagan un commit cada vez que completen una sección del README o cambien el sistema. Mensajes del tipo `Sección 3: matrices de prueba` o `Corrida 4: ajusto el sesgo`.
- **Tiene que haber commits hechos hoy.** El historial es la prueba de que lo hicieron ustedes, paso a paso.
- Para ver el historial: botón **Commits** (el reloj) arriba de la lista de archivos.

## 6. Problemas comunes

| Problema | Solución |
|---|---|
| No aparece el botón Fork | No iniciaron sesión. |
| «You can't fork this repository» | Ya tienen un fork: búsquenlo en su perfil, en Repositories. |
| El compañero no puede editar | No aceptó la invitación de colaborador. |
| Escribieron algo mal | Editen de nuevo y hagan otro commit. Si quieren volver atrás: abran el commit en el historial y copien la versión anterior. |
| No se ven bien las tablas | Dejen una línea en blanco antes y después de cada tabla. |
